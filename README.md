# LU09 Machine Vision ASL

## Improve the App

I am proud of this little web app.
But like all things, it can be improved.
Your goal is to improve the app in **three** ways.
Feel free to use as much LLM coding assistance as you need.
Where are my ideas, but you can come up with your own improvements.

- Improve the user interface with CSS
- Instead of one large image for all the ASL letters, use separate images for each letter.
- Allow a user to reset one letter at a time.
- Add a feature to save the user's progress using [`localStorage`](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)
- Add all the ASL letters to the app.
- Add a word?
